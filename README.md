Portfolio personnel, orienté cybersécurité, présentant mon parcours, mes projets et mes certifications.

## Aperçu

- Page unique (one-page), responsive, bilingue **FR / EN**
- Sections : À propos, Éducation, Expérience & engagement, Projets, Certifications, Contact

## Stack

HTML / CSS / JavaScript vanilla — aucun framework, aucune dépendance externe à installer.

Aucune installation requise : ouvre simplement `index.html` dans un navigateur.
